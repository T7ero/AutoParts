# Исправления для Armtek парсера

## Проблема
Armtek парсер не работал из-за ошибки Selenium:
```
Message: session not created: probably user data directory is already in use, please specify a unique value for --user-data-dir argument, or don't use --user-data-dir
```

## Причина
Несколько процессов Selenium пытались использовать одну и ту же директорию профиля Chrome, что приводило к конфликтам.

## Исправления

### 1. Уникальные user-data-dir
- Каждый запуск Selenium теперь создает уникальную временную директорию
- Используется `tempfile.mkdtemp(prefix=f"chrome_armtek_{uuid.uuid4().hex[:8]}_")`

### 2. Множественные методы инициализации драйвера
- **Метод 1**: С уникальным user-data-dir
- **Метод 2**: Без user-data-dir
- **Метод 3**: С минимальными опциями

### 3. Улучшенная очистка процессов
- Проверка существования процессов перед очисткой
- Очистка временных директорий в /tmp и текущем каталоге
- Уменьшено время ожидания после очистки

### 4. Fallback методы
- **API**: Прямой запрос к API Armtek
- **HTTP**: Парсинг HTML страницы поиска
- **Альтернативные эндпоинты**: Попытка различных URL
- **Selenium**: Только как последний вариант

### 5. Улучшенный парсинг HTML
- Расширенные CSS селекторы для поиска брендов
- Поиск по атрибутам data-brand
- Парсинг структурированных данных (JSON-LD)
- Регулярные выражения для поиска брендов в тексте
- Дополнительный поиск по тексту страницы
- Поиск по JSON данным в скриптах

### 6. Поддержка прокси
- Автоматическое получение прокси из списка
- Поддержка прокси в HTTP запросах
- Поддержка прокси в Selenium (--proxy-server)
- Обработка различных форматов прокси (ip:port, login:password@ip:port)
- **ИСПРАВЛЕНО**: Корректное извлечение IP:port из прокси

### 7. Лучшая обработка ошибок
- Try-catch блоки для каждого метода
- Детальное логирование ошибок
- Graceful degradation при сбоях

### 8. Новые улучшения (последнее обновление)
- **Исправлен формат прокси**: Теперь корректно извлекается IP:port вместо полного URL
- **Расширен поиск брендов**: Добавлены дополнительные селекторы и методы поиска
- **Улучшен парсинг текста**: Поиск потенциальных брендов по паттернам
- **Поиск в скриптах**: Анализ JSON данных в тегах script

### 9. КРИТИЧЕСКИЕ ИСПРАВЛЕНИЯ ПРОКСИ (последнее обновление)
- **ИСПРАВЛЕНО**: Ошибка `407 Proxy Authentication Required`
- **ИСПРАВЛЕНО**: Неправильный формат прокси в HTTP запросах
- **ИСПРАВЛЕНО**: Поддержка прокси с аутентификацией в Selenium
- **УЛУЧШЕНО**: Функция `make_request` для корректной работы с прокси
- **ДОБАВЛЕНО**: Обработка различных форматов прокси (ip:port, login:password@ip:port)
- **ДОБАВЛЕНО**: Повторные попытки при ошибках прокси с экспоненциальной задержкой
- **ДОБАВЛЕНО**: Специальная обработка ошибок 403, 429, ProxyError, Timeout
