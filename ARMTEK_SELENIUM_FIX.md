# Исправление критических ошибок Armtek Selenium парсера

## Проблема
Armtek парсер постоянно падал с ошибкой "tab crashed" и "connection refused", что приводило к полной остановке парсинга. После падения драйвера система пыталась использовать тот же сломанный драйвер.

## Выполненные исправления

### 1. Система восстановления Chrome драйвера
- **Автоматическое пересоздание драйвера** при критических ошибках
- **Обнаружение критических ошибок**: "tab crashed", "chrome not reachable", "connection refused"
- **Безопасное закрытие** сломанного драйвера перед пересозданием
- **Очистка процессов Chrome** перед созданием нового драйвера

### 2. Улучшенное управление пулом драйверов
- **Fallback создание драйвера** если пул пуст
- **Проверка состояния драйвера** перед использованием
- **Автоматическое восстановление** при недоступности драйвера

### 3. HTTP API Fallback для Armtek
- **Новая функция `parse_armtek_api_fallback()`** для HTTP парсинга
- **Регулярные выражения** для извлечения брендов из HTML
- **Фильтрация артикулов** и технических строк
- **Автоматическое переключение** при падении Selenium

### 4. Оптимизированные настройки Chrome
```bash
--no-first-run
--no-default-browser-check
--disable-logging
--disable-gpu-logging
--silent
--disable-crash-reporter
--disable-in-process-stack-traces
--log-level=3
--disable-dev-tools
--disable-software-rasterizer
```

### 5. Улучшенная обработка ошибок
- **Детальное логирование** всех этапов восстановления
- **Graceful degradation** - переход на альтернативные методы
- **Предотвращение бесконечных циклов** при критических ошибках

## Логика работы

### При нормальной работе:
1. Получение драйвера из пула
2. Загрузка страницы Armtek
3. Парсинг брендов через Selenium
4. Возврат драйвера в пул

### При критической ошибке:
1. **Обнаружение ошибки** ("tab crashed", "connection refused")
2. **Закрытие сломанного драйвера**
3. **Очистка процессов Chrome**
4. **Создание нового драйвера**
5. **Повторная попытка** загрузки страницы
6. **При неудаче** - переход на HTTP API fallback

### HTTP API Fallback:
1. **Прямой HTTP запрос** к странице поиска
2. **Парсинг HTML** через регулярные выражения
3. **Извлечение брендов** из различных HTML элементов
4. **Фильтрация результатов** от артикулов и технических строк

Теперь Armtek парсер работает стабильно даже при:
